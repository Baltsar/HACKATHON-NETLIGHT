# Pass B — user's category, last 30 days

Not Källan's competitor landscape. When the user drops a coffee app (or a video of one), search *that* category.

## Flow

```
Pass A  mechanic + category   "order coffee, skip the queue"
Pass B  Tavily time_range=month
        1. "{category} app launch OR demo OR Product Hunt"
        2. "{category} first seconds hook 2026"
        3. "{named rival} demo OR launch"
Super   compare their 10s to those openings
```

## Return (not a McKinsey deck)

```
rivals[]:        {name, url, hook, grammar, steal, avoid}   // max 3
category_cliche: string
better_hook:     ≤8 words
gap:             one line  // what they hide that a rival shows
idea_upgrade:    optional shot fix, never a pivot
```

`idea_upgrade` = "show secret menu at 2s". Not "become a B2B roastery ERP".

## Rules

- Cite URLs in `because[]`
- <2 hits → say so, drop confidence, do not invent Starbucks-generic
- Video input: 10s → mechanic → same Pass B. Not 3 min frames
- Cannot categorize → one question, then search

## Coffee template (live 30d signal)

- Cliche: latte pour + "your perfect cup"
- Steal: order-ready time on screen at 0s (7 Brew: drink starts when you arrive)
- Avoid: CGI steam, talking-head barista
- Better hook: "Coffee at the door in 12 minutes."
- Gap: rival shows checkout; user cut never leaves splash
